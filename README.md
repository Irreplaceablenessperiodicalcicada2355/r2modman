# r2modman

**r2modman** is a Thunderstore mod manager for Valheim and other games on the store. Install, update, Linux build. Profile per game. vs the Thunderstore app.

## How to use
1. Download v3.2.0.
2. Extract `r2modman.zip`.
3. Pick the game (Valheim first).
4. Install mods from Thunderstore, launch.

## FAQ

**Safe?**
This zip is the desktop manager. Download only from this GitHub.

**vs Thunderstore?**
Same store index. This is the r2modman client.

**Linux?**
Yes. Notes in `files/linux/`.

## Requirements
Windows 10/11 or Linux. Game install on disk.
