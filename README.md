## 🔧 Troubleshooting Tips

### Game Won't Launch?

Make sure you've installed at least one mod først. Some games require mods to be active for r2modman to hook properly. Also, check that your antivirus isn't blocking the application - you may need to add an exception. 



### Mods Not Showing Up?

Verify that you have enabled the mods in your profile. Sometimes mods install disabled by default. Also, ensure the mod is compatible with your game version. Check the mod page for compatibility notes. 



### Performance Issues?

Try disabling some mods to see if performance improves. Some mods can be resource-heavy, especially graphical enhancements. You can also try updating your graphics drivers.
